## 上传 GitHub

解压，将 index.html、one-to-one-offline.html、legacy.html、.nojekyll、README.md 上传到原仓库根目录，替换同名文件并提交。不要只上传ZIP。沿用现有 GitHub Pages 的发布分支和目录，等待部署完成后强制刷新（Mac：Command+Shift+R；Windows：Ctrl+F5）。

## 离线使用

双击 one-to-one-offline.html 即可，不需要安装、API 或联网。访问官方资料链接需要联网。若要保留原工作台入口，请把 legacy.html 放在同一目录。离线快捷分析不是联网AI推理，而是按已选择年级、学科、口述信息及本地知识库生成的教学参考。

## 新的工作流程

1. 选择地区、年级、学科；填写已知分数及经核实的满分。分数未知可留空，不默认100分。城市、家长原话为可选补充。
2. 生成电话沟通分析。同页展开整体得分概览、知识点解读、例题、可能失分表现、追问、后续衔接和可复制话术。无需姓名，也不要求建学生档案。
3. 默认展开最多3个候选模块，可在同页增减。不要把候选模块误说成已确认的失分点。核对孩子实际教材、已学章节和作答。
4. 如有经核对的同卷数据，在“有数据，再谈占比”补充试卷年份、来源、模块分值和样本评分。每题只归一个模块，避免重复计分；不能把单卷占比说成地区固定考试占比。
5. 只有生成家长规划时，才输入姓名和每周学习分钟预算。方案包含具体知识点、验证任务、阶段行动和观察方法。可打印/保存PDF、下载独立HTML或导出2160×3840 PNG概览。概览不替代完整方案，详细依据和预算见HTML/PDF。

## 专业内容与数据边界

- 包含92张学段知识卡，覆盖配置中的学科，不等于覆盖所有教材章节；低年级数学增补了凑十、表内乘除模块。模块依年级范围筛选，部分主题仍需人工核对实际学期和已学范围。
- “为什么考”、例题、教学动作、衔接风险和话术是自编教学解读；不是官方历年真题、评分标准或对孩子的正式测评。
- 课程框架引用教育部义务教育课程标准（2022年版）及普通高中课程标准（2017年版2020年修订）的发布入口。课程框架不能替代当地当年的考纲、试卷、教材或政策。港澳台选择时会提示适用性尚未核对。
- 地区选择用于背景标识和当地教育/考试机构入口。本包没有经核对的地方考试分项数据库，不会仅凭地区生成“本地高频考点”或具体分值比例。
- 总分得分率=已知分数/已知满分。总分差额不被自动拆为考点失分。
- 该卷分值占比=经核对的模块分值/该试卷满分；个人样本得分率=样本实得分/样本满分；两者不是掌握率，也不是考试统计难度。
- 难度展示为教学任务层级（概念理解、换情境运用、多条件整合），不伪造官方难度系数。统计难度还需代表性群体的实际作答数据。
- 未提供试卷数据时，不生成伪雷达分数、失分分布、考试占比、排名或提分承诺。

## 原资料与功能

legacy.html 保留经过白屏修复的原工作台，继续使用原 localStorage 键（one-to-one-v2）。同一网址源、同一浏览器打开即可继续读取既有档案。新快捷分析不自动保存本次表单、姓名或家长报告，也不修改原档案。

如更换网址、浏览器或设备，请在原工作台先导出备份并妥善保管。姓名仅在本次家长方案及用户主动下载的文件中使用，电话分析和电话话术不包含姓名。
