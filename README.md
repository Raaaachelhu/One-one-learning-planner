# 一对一 · 全科学情规划工作台

developer：Rachel Hu

纯静态网站，可在GitHub Pages访问，也可下载HTML后断网使用。不需要API、服务器、安装依赖或账号登录。

## GitHub发布

1. 创建一个独立仓库，本项目仓库为 `Raaaachelhu/One-one-learning-planner`。选择公开仓库通常便于启用GitHub Pages；如需使用私有仓库，请先确认账号计划支持相应Pages功能。
2. 解压本发布包，将 `index.html`、`one-to-one-offline.html`、`.nojekyll`、`README.md` 上传到仓库根目录。不要只上传ZIP文件，也不要把所有文件包在额外的文件夹中。
3. 打开仓库 `Settings → Pages`。
4. 在 `Build and deployment` 选择 `Deploy from a branch`，选择 `main` 分支和 `/(root)`，点击 `Save`。
5. 等待GitHub完成发布，使用Pages页面显示的实际网址。不要把仓库地址当作网站地址。
6. 将实际网站网址发给一线同事。后续更新替换两个HTML文件即可，不会上传浏览器中的学生档案。

## 离线使用

下载 `one-to-one-offline.html`，用Chrome、Edge或Safari打开。也可直接打开本包的 `index.html`。无需联网或登录；官方政策原文链接需要联网打开。

## 一线使用顺序

新建学生档案 → 电话学情规划 → 填写年级、地区、已知分数/薄弱科目与预算 → 学科考点解读中选择学习方向 → 根据电话信息生成规划 → 复制沟通稿/生成4K家长规划海报。

没有试卷也能先规划。口述资料、真实测评与已核对逐题信息分别保留，不虚构知识点掌握率。成绩未知不填0分，满分未知不默认100分；只有可比较的历史成绩才连接趋势。未来阶段路径不是成绩预测。

## 数据与备份

- 每位同事的数据保存在自己的浏览器内，不上传GitHub，不在同事间自动共享。
- 定期点击“备份”，保管导出的JSON档案；在另一浏览器或另一网址中使用“恢复”导入。
- 从旧在线网址切换到GitHub Pages，档案不会自动迁移，应先备份再恢复。
- 试卷图片/PDF只在当前页面会话内查看；档案备份不包含原始资料。
- GitHub Pages访问权限取决于仓库和账号配置，本网站没有另建团队账号或成员权限系统。

共90张学习卡：小学22张、初中36张、高中32张。覆盖当前配置的全部科目；提供本学段主要学习及先修框架，不等于覆盖每本教材全部章节。每张卡包含考查能力、自编例题和解析、可能失分表现、电话追问、教学行动、样本统计、家长沟通示例和课程框架来源。可按学科搜索、复制、导出完整文本和2160×3840海报；最多选择6个方向进入电话沟通稿、周计划和海报。

## 个性化知识点规划增强版

- 从「电话学情规划」填写已知分数与家长原话，也可从「学生画像」完善年级、年龄、教材、目标和时间预算。
- 在「个性化学习规划」顶部补充正在学的章节、具体卡点与独立程度。内容即时更新，不需联网或 API。
- 按反馈偏弱、确认题目失分、已知得分率安排最多3门重点科目；按手选模块、题目标签、情况关键词、年级主题选择知识模块。
- 每门学科可手动勾选最多4个知识模块；未手选时自动推荐最多3项。每项展开知识拆解、先修顺序、探测例题、解析、教学动作和家长解释。
- 周计划采用探测、修复、变式、复测的模块循环，全部展开。每日自主时间按科目分配，总和不超预算；预算为0时任务放在课内。未达标需回退，未来周次是拟定路线。
- 电话沟通文本、周计划 CSV、家长报告文本及已有4K图片导出使用增强后的知识点和周任务。页面可打印成 PDF。
- 无试卷时输出候选方向，不根据分数虚构知识点掌握率。教学示例非考试真题，章节与教材需教师核对。
- 原有本机档案键值保持兼容；新增 rhProfile 保存章节、卡点、独立程度和手选知识模块。恢复旧版备份可继续使用。

## 白屏修复（2026-10-14）

原因：增强模块 RHBlock 错把 JSX runtime 当作 React 调用 createElement，导致默认首页渲染异常。已改用打包内已有的 React createElement 接口。

更新方法：解压后将 index.html 和 one-to-one-offline.html 上传至原仓库根目录，选择替换同名文件并提交；待 Pages 部署完成，强制刷新页面（Mac：Command+Shift+R；Windows：Ctrl+F5）。保留原网址和浏览器即可沿用已有本机档案。
