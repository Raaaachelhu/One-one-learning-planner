# 一对一 · 全科融合增强版

developer：Rachel Hu

## 发布与离线使用

解压，将本包内 index.html、one-to-one-offline.html、legacy.html、.nojekyll、README.md 上传到原GitHub仓库根目录，替换同名文件并提交。沿用原Pages发布分支，部署完成后强制刷新。不要只上传ZIP，也不要包在多一层目录下。

双击 one-to-one-offline.html 可离线使用。三个HTML应保持在同一目录，完整工作台由 legacy.html 提供。纯静态本地规则分析，不需要API；访问官方资料链接需要联网。

## 快速沟通：已支持多选学科

选择地区、年级，在学科列表中勾选一门或多门。每门分别填写分数、满分和可选的学科情况；成绩未知留空。共同家长反馈为可选项。

点击生成后，同页展示全科成绩概览和每科完整分析。各科可独立选择最多3个重点，分别查看考什么、怎么考、自编例题、可能失分表现、教学层级、后续衔接风险、追问和可复制话术。复制全科沟通稿可同时输出全部学科。

每科试卷分值及样本评分分别录入、计算与保存，不与其他科串用；更改所选知识模块会清除该科先前的分项数据，需要重新核对。

## 家长方案：姓名只在此填写

填写姓名、全科每周总时间及各科时间分配。各科分钟合计必须等于总预算，不能每科都重复使用总预算。默认均分，可按实际目标修改；不按跨科得分率自动排列强弱。

生成一个完整全科方案：总览、各科时间分配、各科知识点、验证任务、阶段行动、进步观察与数据依据。可下载一份全科HTML或打印PDF；4K概览按学科分别导出，避免多科挤进一张图。

改变电话输入、知识模块或分项数据，会使旧家长方案失效，需重新生成，以免使用旧信息。

## 完整工作台：功能已放回主页面

主页面下方有明显入口：总览驾驶舱、学生画像与档案、试卷与成绩诊断、学科考点解读、全科知识地图、地区与升学政策、个性化学习规划、家长报告与复盘。展开内嵌完整工作台即可使用，也可单独打开。

快速沟通与完整工作台保留不同的操作区，避免原档案和诊断工具被简化删除。通过“将本次分析写入学生档案”新增本次多科记录，不覆盖已有学生。若未生成家长方案，记录名称默认为“电话沟通记录”，不额外索要姓名。

口述分数写入档案时标注来源待核对，不作为已确认考试评分。家长反馈和已选知识方向写入电话规划信息，不自动生成已确认逐题诊断。

也可下载JSON，在完整工作台右上角“恢复”导入。浏览器限制本地文件内嵌访问或存储时，请单独打开 legacy.html 并用JSON恢复。

旧档案继续使用 one-to-one-v2 / zhixing-v1 本机键。同一网址源和浏览器可读取原记录；换网址、浏览器或设备，请先在原工作台备份，再恢复。快速分析不自动保存姓名；只有主动下载文件或写入档案时持久保存。

## 内容与数据边界

- 快速分析含92张学段知识卡，原工作台保留原有专业资料。范围不等于所有教材全部章节；需核对实际已学进度。
- 教育部课程标准发布入口提供框架参考。例题、教学解释、风险和话术为自编内容，不是官方真题、标准答案或测评结论。
- 地区用作背景与当地考试/教育机构入口，未接入经核对的各地区试卷数据库，不生成虚构的地区固定占比。
- 电话口述成绩用于整体展示，不自动拆为知识点失分。不同考试、学科、难度的得分率不可直接作为能力排名。
- 该卷分值占比=模块分值/对应试卷满分；个人样本得分率=样本实得分/样本满分。确认每题只归入一个模块，避免重复统计。
- 难度层级是教学解释，统计难度需要代表性群体作答数据，不用个人样本得分率冒充。
- 候选方向先验证，未学内容不能认定为薄弱；不作固定提分或录取保证。

## 本轮新增：地区竞争背景与个人位置参考

快速输入中的地区应为拟报名归属，不能仅填居住地。城市/区县已移到基本信息区；广东选择广州或深圳、四川选择成都才匹配对应城市资料。其他城市不会自动套用这些城市数据。

生成学情分析后，主页面新增完整地区背景面板：资料年份、预计考试年份、已核对的规模或政策指标、招生结构说明、可复制的地区沟通说明、来源和发布/核对日期。目标考试可切换中考或高考，资料年份可切换2026或2025；没有匹配资料明确显示待补充。

### 覆盖范围

本版内置8组地区/考试组合、9条年份快照：

- 北京中考2026：中考报名12.6万人、政策公布普高招生规模约9.5万人、计分总分510分、优质高中计划分配至初中校的口径及科目计分结构。
- 北京中考2025：普高招生规模约8.5万人及计分总分，用于历史规模背景。
- 广州中考2026：梯度投档设置、户籍/学籍与计划类别、达到控制线不等于录取等规则；未核验完整报名与普高计划总量。
- 深圳中考2026：总分630分、单科等级设置比例及分批招生；未核验完整录取率。
- 成都中考2026：“5+2”区域招生组织背景；未核验地区完整规模与录取分布。
- 北京高考2026：总分750分与同年分数分布入口；未核验完整考生规模和录取率。
- 山东高考2026：普通高考总报名、春季报名与夏季参加考试规模的口径区分；这些人群不能混算本科录取率。
- 浙江高考2026：750分、选考赋分及考试机会、官方分数段入口，另展示所选科目的计分结构。
- 上海高考2026：官方同年各类别成绩分布入口及选考科目分布查询说明；未核验完整考生规模和录取率。

数据查核日期2026-10-14，来源链接和发布日期在各地区面板中展示。全国其他地区保留官方资料入口，但未建立完整定量地区库。本版不声称覆盖全国所有考生地区，也不输出未经依据的全国竞争排名。

北京2026年9.5万/12.6万约75.4%仅称“招生规模/报名规模参照”；约数口径及人群不逐一对应，不能称作实际普高录取率或个人录取概率。2025至2026规模增幅仅比较公布规模，不能据此宣称个人竞争一定减轻。

小学仅显示未来升学衔接背景，不能将中考数据当成小学竞争判断。预计考试年按正常学制推算，需要核对；资料年与预计考试年不同会提示，未来届别政策需复核。

### 个人竞争位置

可选填写同场考试的比较范围（班级/学校/区县/城市/省级同类）、考试名称年月及来源、真实名次与参考人数；目标名次由用户自行填写。

名次比例=名次/同场人数，未调整同分。班级与校内排名不能换成区市排名，学习得分率不能换成考生位次。目标名次差额不表示学校录取资格或概率；各科分数不自动相加推算地区位置。

这部分结果连同地区数据进入全科HTML/PDF家长方案。4K学科概览仍集中展示学习安排，地区说明详见完整方案；不会把全部信息挤在单张图片内。写入完整工作台的沟通档案会保留地区参考年份、预计考试年、来源和已填位次，旧记录不覆盖。

### 数据维护

可下载“地区数据样本.json”修改后加载；需要明确province、city、exam、year、metrics、rules、action、sources和checked。导入数据标为用户提供，来源真实性需自行复核，不冒充本包官方资料。每条来源须含标题、发布日期及http/https链接。导入只对本次会话生效；如需长期更新发布包，应维护内置快照后重新发布。

本包仍为纯离线分析，不会自动联网拉取最新地区政策。网页中的官方链接需联网访问。
