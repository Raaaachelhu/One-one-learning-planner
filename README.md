# 一对一 · 全科融合增强版

developer：Rachel Hu

## 发布与离线使用

解压，将本包内 index.html、one-to-one-offline.html、legacy.html、.nojekyll、README.md 上传到原GitHub仓库根目录，替换同名文件并提交。沿用原Pages发布分支，部署完成后强制刷新。不要只上传ZIP，也不要包在多一层目录下。

双击 one-to-one-offline.html 可离线使用。三个HTML应保持在同一目录，完整工作台由 legacy.html 提供。纯静态本地规则分析，不需要API；访问官方资料链接需要联网。

## 快速沟通：已支持多选学科

选择地区、年级，在学科列表中勾选一门或多门。每门分别填写分数、满分和可选的学科情况；成绩未知留空。共同家长反馈为可选项。

点击生成后，同页展示全科成绩概览和每科完整分析。各科可独立选择最多3个重点，分别查看考什么、怎么考、自编例题、可能失分表现、教学层级、后续衔接风险、追问和可复制话术。复制全科沟通稿可同时输出全部学科。

每科试卷分值及样本评分分别录入、计算与保存，不与其他科串用；更改所选知识模块会清除该科先前的分项数据，需要重新核对。

## 家长方案：姓名只在此填写

填写姓名、全科每周总时间及各科时间分配。各科分钟合计必须等于总预算，不能每科都重复使用总预算。默认均分，可按实际目标修改；不按跨科得分率自动排列强弱。

生成一个完整全科方案：总览、各科时间分配、各科知识点、验证任务、阶段行动、进步观察与数据依据。可下载一份全科HTML或打印PDF；4K概览按学科分别导出，避免多科挤进一张图。

改变电话输入、知识模块或分项数据，会使旧家长方案失效，需重新生成，以免使用旧信息。

## 完整工作台：功能已放回主页面

主页面下方有明显入口：总览驾驶舱、学生画像与档案、试卷与成绩诊断、学科考点解读、全科知识地图、地区与升学政策、个性化学习规划、家长报告与复盘。展开内嵌完整工作台即可使用，也可单独打开。

快速沟通与完整工作台保留不同的操作区，避免原档案和诊断工具被简化删除。通过“将本次分析写入学生档案”新增本次多科记录，不覆盖已有学生。若未生成家长方案，记录名称默认为“电话沟通记录”，不额外索要姓名。

口述分数写入档案时标注来源待核对，不作为已确认考试评分。家长反馈和已选知识方向写入电话规划信息，不自动生成已确认逐题诊断。

也可下载JSON，在完整工作台右上角“恢复”导入。浏览器限制本地文件内嵌访问或存储时，请单独打开 legacy.html 并用JSON恢复。

旧档案继续使用 one-to-one-v2 / zhixing-v1 本机键。同一网址源和浏览器可读取原记录；换网址、浏览器或设备，请先在原工作台备份，再恢复。快速分析不自动保存姓名；只有主动下载文件或写入档案时持久保存。

## 内容与数据边界

- 快速分析含92张学段知识卡，原工作台保留原有专业资料。范围不等于所有教材全部章节；需核对实际已学进度。
- 教育部课程标准发布入口提供框架参考。例题、教学解释、风险和话术为自编内容，不是官方真题、标准答案或测评结论。
- 地区用作背景与当地考试/教育机构入口，未接入经核对的各地区试卷数据库，不生成虚构的地区固定占比。
- 电话口述成绩用于整体展示，不自动拆为知识点失分。不同考试、学科、难度的得分率不可直接作为能力排名。
- 该卷分值占比=模块分值/对应试卷满分；个人样本得分率=样本实得分/样本满分。确认每题只归入一个模块，避免重复统计。
- 难度层级是教学解释，统计难度需要代表性群体作答数据，不用个人样本得分率冒充。
- 候选方向先验证，未学内容不能认定为薄弱；不作固定提分或录取保证。
